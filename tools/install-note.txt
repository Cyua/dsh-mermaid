__NAME__ __VERSION__ — DeepSeek Harness 的 Mermaid 图表插件
==========================================================

支持环境：DeepSeek Harness 桌面版（Web UI）。已在 DSH desktop 0.2.2-rc.3 验证。

安装方式 A（推荐，无需解压）：直接安装 .tgz
------------------------------------------------
1. 把 cyua-__NAME__-__VERSION__.tgz 放到任意目录（之后可以删除或移走，DSH 会安装一份副本）。
2. 在 DSH 的插件页「添加插件」里选择「压缩包 / Tarball」，填入这个文件的完整路径；
   或者在对话里执行：
   plugin_manager  action = install_bundle
                   target = D:\下载\cyua-__NAME__-__VERSION__.tgz
3. 插件列表出现 “cyua-mermaid-render” 并启用后，刷新页面（或重启 DSH）即可。

安装方式 B（文件夹）：解压 zip
--------------------------------
1. 解压 zip 到一个固定目录，例如 D:\AI\plugins\__NAME__-__VERSION__
   注意：这种方式 DSH 会链接到该目录，安装后不要删除或移动它。
2. 在 DSH 里执行：
   plugin_manager  action = install_bundle
                   target = D:\AI\plugins\__NAME__-__VERSION__
3. 同样确认 “cyua-mermaid-render” 已启用，然后刷新页面。

两种方式选一种即可，不要重复安装。

功能速览
--------
- mermaid 代码块直接渲染成内嵌 SVG 卡片：查看/复制源码、适应宽度、原始大小、
  全屏查看（八向拖拽缩放、双击标题栏铺满），并可**另存为 PNG 图片**。
- 跟随 DSH 深/浅色主题，自动修复浅色填充导致的对比度问题。
- 流程图 subgraph 分组、序列图参与者自动分配不同颜色。
- 视口懒渲染：历史里很远的图不会一次性全部渲染。
- 自带 Mermaid 12，离线可用，无外部依赖。

卸载
----
plugin_manager  action = remove_bundle
                target = @cyua/dsh-mermaid
